日历打勾 v0.1.0 · 简体中文版

适用：macOS 14 及以上，Apple Silicon Mac（M 系列芯片）。

安装
1. 把“日历打勾.app”拖到“应用程序”后打开。
2. 在应用设置窗口允许“日历访问”（完全访问）。
3. 在系统设置 → 隐私与安全性 → 辅助功能中允许“日历打勾”。
   如果没有条目，点击 + 添加应用程序里的 app。

首次下载提示
本版本使用固定的本地证书签名，尚未通过 Apple Developer ID 签名或 Apple 公证。
如果 macOS 阻止打开，请先核对 GitHub 下载来源，再按 Apple 官方说明在
“系统设置 → 隐私与安全性”中允许打开：
https://support.apple.com/zh-cn/102445

使用
右键苹果日历里的一个日程，原菜单旁会显示“标记为已完成”。
点击后，日程标题变成“✓ 原标题”。再次右键，点击“取消完成”可恢复。
Control + 单击也支持。重复日程只修改本次。

设置窗口内的示例可以免授权试用，不会修改真实日历。
关闭设置窗口后工具继续运行；菜单栏图标可以暂停或退出。
当前没有开机自启。建议先放到固定位置再授权。

限制与隐私
只读日历及带参与者的会议暂不支持修改。
完成状态保存为标题前缀，会随日历账户同步；退出本工具后仍可见。
日程数据不会上传，不保存日程副本。
目前针对简体中文和美式数字日期识别，其他语言仍需验证。
